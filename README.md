# فامیلی فردا — اتاق ارائه هیئت‌مدیره هایپرفامیلی

نسخه ۱.۰ · مرجع پژوهش: ۱۶ اکتبر ۲۰۲۶ · بسته ارائه: ۱۷ اکتبر ۲۰۲۶

## طراحی بصری به‌روز

رابط با زمینهٔ روشن گرم، سبز عمیق و تأکید طلایی، جلد تصویری، کارت‌های منظم و تایپوگرافی فارسی بازطراحی شده است. فونت Vazirmatn با مجوز OFL داخل بسته و فایل مستقل قرار دارد و برای نمایش متن به اینترنت نیاز ندارد. نسخهٔ پوشه‌ای و `START-HERE.html` هر دو با این طراحی بازسازی شده‌اند. گزارش بررسی این تغییر در `docs/VISUAL-REFRESH.md` است.

## اجرای فوری برای جلسه

فایل `START-HERE.html` در ریشه این بسته را با Chrome یا Edge باز کنید. این فایل مستقل است؛ متن‌ها، داده‌ها، تصاویر سند مدیر و کتابخانه داخل آن قرار دارند. برای خواندن محتوای اصلی به سرور، نصب Node، اینترنت یا حساب کاربری نیاز نیست. لینک وب‌سایت‌ها و ویدئوهای خارجی طبیعتاً اینترنت می‌خواهند.

در نمای کلی، یکی از سه نگاه «مدیریت»، «کارکنان» یا «مشتری نهایی» را انتخاب کنید. در «جلسه من»، فهرست را مرتب کنید و دکمه ارائه را بزنید. مسیر اولیه شامل ۱۲ طرح پیشنهادی برای آغاز گفت‌وگو است، نه اولویت مصوب. دکمه «همه ۱۰۲ طرح» تمام فهرست را وارد جلسه می‌کند؛ هیچ پرونده‌ای از کاتالوگ حذف نشده است.

روایت هر طرح شش مرحله دارد: معرفی، ارزش برای سه گروه، ایران و جهان، قیمت و دامنه، اجرا و ریسک، جمع‌بندی. در تمام مراحل می‌توان اصل پرونده را از نماد سند باز کرد. نام شرکت و دکمه‌های منبع، سطح مشاهده و محدودیت شاهد را نشان می‌دهند.

پیش از جلسه، همین فایل را روی لپ‌تاپ ارائه‌دهنده یک‌بار باز کنید و نمایشگر اصلی/پروژکتور را بررسی کنید. اپ درون این چت میزبانی نشده است؛ پیش‌نمایش فایل جای اجرای محلی را نمی‌گیرد.

اصل فایل‌های Word مکمل پروژه در `public/downloads/supporting-originals.zip` قرار دارد. متن استخراج‌شده آنها در کتابخانه با برچسب مرجع تاریخی/مکمل است؛ این اسناد وضعیت تأییدشده هایپرفامیلی نیستند. تصاویر و صفحه‌آرایی Word در فایل اصلی باقی می‌مانند. PDF اصلی مدیر، Excel اصلی قیمت‌ها و ZIP اصلی پژوهش از داخل اپ نیز قابل دریافت‌اند.

## کنترل‌های جلسه

- `←` یا `Space`: مرحله بعد؛ `→`: مرحله قبل. Space روی دکمه دارای فوکوس، همان دکمه را فعال می‌کند.
- `1` تا `6` انگلیسی: انتخاب مرحله روایت؛ `Home` و `End`: ابتدا و انتهای مسیر.
- `F`: درخواست تمام‌صفحه؛ `Esc`: بستن جزئیات یا خروج از ارائه.
- `Ctrl+K` یا `⌘+K` و همچنین `/`: جست‌وجوی سریع. جست‌وجوی متن کامل در کتابخانه است.

فهرست و یادداشت‌ها در مرورگر ذخیره می‌شوند و میان دستگاه‌ها خودکار مشترک نیستند. از «خروجی جلسه» یک فایل JSON بگیرید و روی لپ‌تاپ دیگر با «ورود فایل» بازیابی کنید. جمع‌بندی «نامزد پایلوت» یا موارد دیگر، پیش‌نویس محلی‌اند و هیچ مصوبه سازمانی ایجاد نمی‌کنند.

یادداشتِ مرحله جمع‌بندی روی همان نمایشگر ارائه دیده می‌شود. اطلاعاتی که نباید روی پروژکتور باشد در آن ننویسید. سناریوی نفرساعت در بخش قیمت، محاسبه موقت است و با تعویض طرح بازنشانی می‌شود؛ نرخ و خروجی آن داخل فایل جلسه ذخیره نمی‌شوند.

## قواعد خواندن شواهد

قیمت جزء/اشتراک، بودجه کامل اجرا نیست. قیمت دستگاه اپراتوری با وندینگ مستقل هم‌رده نیست. ارزهای مختلف به هم تبدیل نشده‌اند. نرخ نفرساعت سناریویی، نرخ بازار، حقوق یا پیش‌فاکتور نیست. مجهول به صفر تبدیل نشده و عکس سند مدیر به‌عنوان اثبات نصب یا مدل نهایی خرید معرفی نمی‌شود.

این بسته، گردآوری و ارائه پژوهش موجود است؛ مرحله جدیدِ راستی‌آزمایی سراسر وب نیست. وضعیت و تاریخ دسترسی منابع از ثبت پژوهش آمده‌اند. تعریف‌های کوتاه طرح‌ها بازآرایی تحلیلی‌اند؛ اصل هر فایل بدون جایگزینی در کتابخانه محفوظ است.

## ساختار فنی

`src/00-core.jsx`: اجزای مشترک، قالب‌های شاهد، نمایشگر Markdown، محاسبه سناریویی و دیالوگ.

`src/10-views.jsx`: نمای کلی، کاتالوگ، پرونده پنج‌بخشی، اجرا و قیمت‌نامه.

`src/20-research.jsx`: اطلس، کتابخانه، سند مدیر، منابع و جست‌وجو.

`src/30-session.jsx`: فهرست و جمع‌بندی جلسه، مقایسه و روایت شش‌مرحله‌ای.

`src/40-app.jsx`: وضعیت برنامه، ورودی/خروجی جلسه، مسیرهای hash، ذخیره محلی و کلیدهای میانبر.

`src/style.css`: طراحی RTL، اندازه متن، حرکت، نمایش موبایل و ارائه.

`public/`: نسخه پوشه‌ای آماده اجرا/میزبانی داخلی؛ بدون build سمت کاربر. برای ارائه مستقل، `START-HERE.html` ریشه ساده‌تر است.

`docs/`: گزارش پوشش، کنترل یکپارچگی و محدودیت‌های آزمون.

### بازسازی کد رابط

```sh
npm install
npm run build
python3 scripts/standalone.py
```

بازسازی JSX با TypeScript 5.8.3 انجام می‌شود. TypeScript در این مسیر نقش تبدیل JSX را دارد؛ این خروجی ادعای type-check کامل ندارد. کد رابط از React استفاده می‌کند. برای اجرای کاملاً بدون نصب در محیط ساخت محدود، نسخه‌های محلی React 16.0.0 و ReactDOM 16.0.1 در `public/vendor` بسته‌بندی شده‌اند؛ نسخه آنها پنهان یا به‌عنوان جدیدترین نسخه معرفی نشده است.

برای تبدیل این ارائه محلی به یک محصول وب سازمانی پایدار، ارتقای وابستگی‌های قدیمی، بازبینی امنیت و آزمون مرورگرهای سازمان لازم است. این بسته نباید بدون آن بررسی به‌عنوان سامانه تولیدی دارای احراز هویت تلقی شود.

### بررسی یکپارچگی داده

```sh
python3 scripts/check_data.py
```

این فرمان مسیرها، ارجاع‌ها، داده قیمت، جمع ساعات، SHA-256 متن‌ها و برابری بایت‌های ۷۲۳ فایل با آرشیو اصلی را کنترل می‌کند.

برای بازسازی داده از ورودی‌های اصلی، پوشه‌ای شامل فایل‌های اولیه گفت‌وگو با نام اولیه تهیه کنید و متغیر `FAMILI_INPUT_DIR` را به آن بدهید. ابزار `scripts/data.py` به Python و بسته‌های PyMuPDF، python-docx، Pillow، PyYAML، mistune و bleach نیاز دارد. سپس `scripts/enrich.py` تعریف‌های تحلیلی و نگاشت منابع را اضافه می‌کند. برای ویرایش رابط، بازسازی داده لازم نیست.

### پیش‌نمایش محلی با سرور

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory public
```

این فرمان فقط روی خود دستگاه گوش می‌دهد. انتشار واقعی روی سرور در این کار انجام نشده است.

## محرمانگی و انتشار

بسته حاوی اسناد پروژه است. فایل یا پوشه را بدون کنترل دسترسی، عمومی نکنید. برای میزبانی، فقط پوشه `public` پس از بررسی محرمانگی، پشت HTTPS و احراز هویت سازمانی قرار گیرد. فایل‌های منبع و اسناد هم به همان کنترل دسترسی نیاز دارند؛ مخفی‌کردن لینک یا `noindex` امنیت ایجاد نمی‌کند. اپ فعلی API سازمانی، اتصال صندوق، پرداخت واقعی، هوش مصنوعی مولد زنده یا ثبت مصوبه روی سرور ندارد و چنین قابلیتی را شبیه‌سازی نمی‌کند.

حقوق تصاویر، متون و داده‌های ورودی متعلق به صاحبان اصلی است؛ آماده‌سازی برای جلسه، مجوز انتشار عمومی آنها نیست. لوگوی فامیلی از فایل ارسالی کاربر، بدون تغییر، در رابط استفاده شده است؛ نوشته‌های داخل دو تصویر تولیدی، بازتفسیر تصویری آن هستند. نقشه زمینه از داده کم‌دقت Natural Earth است و نقاط نماینده منطقه‌اند، نه محل دقیق شعب.

## آرشیو ورودی‌های قبلی

پوشه `input-archives` نسخه‌های ZIP قبلیِ در دسترس این پروژه را نیز بدون تغییر نگه می‌دارد؛ بعضی نسخه‌ها تجمعی و تکراری‌اند. این آرشیوها برای جلوگیری از از‌دست‌رفتن ورودی‌ها همراه بسته‌اند؛ شمار ۷۴۹ سند، تعداد نمایه‌های کتابخانه است و به معنی بازکردن و افزودن دوباره تک‌تک اقلام تکراری همه ZIPها نیست. فهرست و SHA-256 آنها در `docs/input-archives.json` ثبت شده است.

نتایج و محدودیت دقیق آزمون مرورگر در `docs/QA.md` آمده است.

## نسخهٔ تصویری و متحرک

جلد اختصاصی، ۱۶ عکس در نمای کلی، گالری قابل کلیک، کارت‌های تصویری، جلد تازهٔ ارائه و انیمیشن‌های ورود و پیمایش به نسخه افزوده شده‌اند. دکمهٔ حرکت در نوار بالا امکان توقف می‌دهد و کاهش حرکت دستگاه رعایت می‌شود. دو تصویر جدید مفهومی‌اند و برچسب دارند.

فایل `START-HERE.html` نسخهٔ مستقل و کاملاً آفلاین است. جزئیات و پرامپت تصاویر در [گزارش طراحی](docs/CINEMATIC-DESIGN.md) و نتایج کنترل در [گزارش ماشینی](docs/cinematic-checks.json) ثبت شده‌اند.


## هویت هایپرفامیلی و منوی تازه

نسخهٔ فعلی با فیروزه‌ای نمونهٔ ارسالی و لوگوی اصلی فامیلی بازطراحی شده است. منوی کناری حذف و با سربرگ تمام‌عرض، ناوبری فصل‌ها و منوی تصویری تمام‌صفحهٔ «نقشهٔ فردا» جایگزین شده است. تصویر فروشگاه و کافه، تابلو و تجهیزات با برند فامیلی دارند و مفهوم‌های تولیدشده با هوش مصنوعی‌اند. ورود تیتر، حرکت عکس‌ها و بازشدن منو نیز ارتقا یافته‌اند.

نسخهٔ آماده: [START-HERE.html](START-HERE.html). جزئیات هویت، خروجی‌ها و آزمون‌ها: [BRAND-DESIGN.md](docs/BRAND-DESIGN.md).
