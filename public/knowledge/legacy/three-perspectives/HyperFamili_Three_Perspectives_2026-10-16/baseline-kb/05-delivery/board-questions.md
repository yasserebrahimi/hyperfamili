# پرسش‌های سخت هیئت‌مدیره و پاسخ پیشنهادی

| پرسش | پاسخ قابل دفاع |
|---|---|
| چرا پروژه تازه وقتی ERP داریم؟ | ابتدا قابلیت موجود را بررسی می‌کنیم؛ پیشنهاد، تکمیل تجربه/تصمیم/عمل است، نه الزام تعویض ERP. |
| دقیقاً چقدر سود می‌سازد؟ | اکنون عدد قطعی نداریم؛ مالی پیش از اجرا خط پایه و قواعد شمارش منفعت را تأیید می‌کند. |
| چرا از فروشگاه بدون صندوق شروع نمی‌کنیم؟ | نمونه جهانی نشان می‌دهد فناوری و اقتصاد فرمت دو مسئله جدا هستند؛ مسیر پرداخت عادی در پایلوت حفظ می‌شود. |
| اگر اینترنت قطع شد؟ | هشدار حساس محلی و ثبت صف داده؛ قیمت کهنه مشخص و پرداخت به مسیر معتبر صندوق برگردد. |
| مشتری اپ نصب نمی‌کند چه؟ | وب‌اپ اختیاری، تبلت قرضی و مسیر حضوری عادی؛ حق انتخاب حفظ می‌شود. |
| اگر مدل اشتباه کرد؟ | عدم قطعیت، تأیید انسان، ثبت نسخه، قابلیت توقف و مسیر دستی از روز اول. |
| فروشنده خارجی ایران را پشتیبانی می‌کند؟ | فرض نشده؛ بررسی امکان قانونی، قرارداد، API و قطعه پیش‌نیاز خرید است. |
| چرا این‌همه ایده؟ | ۳۰ ابتکار، نقشه فرصت است؛ فقط سه آزمایش محدود پیشنهاد تأمین مالی می‌گیرند. |
