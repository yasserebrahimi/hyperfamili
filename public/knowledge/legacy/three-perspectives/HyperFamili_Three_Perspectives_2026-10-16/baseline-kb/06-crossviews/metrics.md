# معیارهای سنجش همه ابتکارها

این نمایه، مقادیر کامل فیلدهای ثبت قبلی را دوباره مرتب می‌کند؛ تحلیل، برآورد یا الزام جدیدی به کارت‌ها اضافه نشده است. اولویت و هزینه نسبی، پیشنهاد پژوهشگر هستند و بودجه یا تعهد فروشنده نیستند.

| شناسه | ابتکار | معیار سنجش |
| --- | --- | --- |
| [I01](../02-initiatives/customer-experience/i01.md) | فامیلی همراه؛ سبد خرید در سقف بودجه | تکمیل سبد در بودجه؛ زمان ساخت فهرست؛ خطای قیمت؛ استفاده مجدد. |
| [I02](../02-initiatives/customer-experience/i02.md) | فامیلی پیدا کن؛ راهنمای کالا تا چراغ قفسه | زمان یافتن قلم؛ موفقیت یافتن بدون کمک؛ خطای مکان و مدت برداشت. |
| [I03](../02-initiatives/customer-experience/i03.md) | چرخ خرید ماژولار؛ اول بارکد، بعد بینایی | نرخ استفاده، تکمیل سفر، خطای سبد، زمان صندوق و هزینه نگهداشت هر سفر. |
| [I04](../02-initiatives/customer-experience/i04.md) | صف هوشمند و صندوق سیار | صدک ۹۰ انتظار؛ رهاکردن صف؛ اختلاف پرداخت؛ نیاز به کمک. |
| [I05](../02-initiatives/customer-experience/i05.md) | ترازوی بینا برای میوه و کالای فله | زمان صدور برچسب؛ خطای نوع کالا؛ دفعات مداخله و مغایرت وزن. |
| [I06](../02-initiatives/customer-experience/i06.md) | فامیلی مهمانی؛ سفارش آماده‌سازی‌شونده | سود مشارکت سفارش؛ تحویل به‌موقع؛ دوباره‌کاری و رضایت. |
| [I07](../02-initiatives/customer-experience/i07.md) | تحویل در مسیر؛ جمع‌آوری سفارش و لاکر | زمان انتظار تحویل؛ هزینه هر سفارش؛ عدم مراجعه و شکایت. |
| [I08](../02-initiatives/customer-experience/i08.md) | حالت خرید آسان و دسترس‌پذیر | تکمیل وظیفه توسط کاربران متنوع؛ خطا و نیاز به کمک. |
| [I09](../02-initiatives/customer-experience/i09.md) | رسید و مرجوعی دیجیتال قابل پیگیری | زمان رسیدگی؛ مراجعه تکراری؛ رضایت و خطای بازپرداخت. |
| [I10](../02-initiatives/customer-experience/i10.md) | ویدئوی قابل خرید؛ از دستور غذا تا سبد شعبه | سود افزایشی نسبت به مقایسه؛ تکمیل سفارش؛ نرخ عدم موجودی. |
| [I11](../02-initiatives/store-operations/i11.md) | قفسه تا اقدام؛ نه صرفاً داشبورد | ساعت خالی‌بودن قفسه؛ زمان رفع؛ صحت هشدار و ظرفیت پاسخ. |
| [I12](../02-initiatives/store-operations/i12.md) | قیمت یکسان در قفسه، چرخ و صندوق | نرخ مغایرت قیمت؛ تأخیر به‌روزرسانی؛ وقت اصلاح و شکایت. |
| [I13](../02-initiatives/store-operations/i13.md) | پیش‌بینی و سفارش پیشنهادی محلی | کسری و موجودی مازاد هم‌زمان؛ ضایعات؛ هزینه واقعی و سطح خدمت، نه فقط خطای مدل. |
| [I14](../02-initiatives/store-operations/i14.md) | تازه‌نجات؛ انقضا، تخفیف و فروش مازاد | ضایعات واحدی/ارزشی و حاشیه خالص پس از تخفیف؛ اثر بر فروش عادی. |
| [I15](../02-initiatives/store-operations/i15.md) | سردبان؛ هشدار سرمایش متصل به تعمیرات | زمان تشخیص و واکنش؛ مدت خروج از محدوده؛ هشدار کاذب و تکمیل رسیدگی. |
| [I16](../02-initiatives/store-operations/i16.md) | انرژی‌بان؛ مصرف تا اقدام مهندسی | کیلووات‌ساعت تعدیل‌شده و هزینه اجتناب‌شده؛ بدون افت کیفیت نگهداری یا آسایش. |
| [I17](../02-initiatives/commercial/i17.md) | سود گمشده قرارداد؛ کنترل تخفیف و مطالبات | مطالبات تأیید و وصول‌شده؛ نرخ هشدار غلط؛ زمان تطبیق؛ نه جمع همه هشدارها به‌عنوان سود. |
| [I18](../02-initiatives/commercial/i18.md) | تخفیف سودآور؛ آزمایش به‌جای فروش ظاهری | حاشیه مشارکت افزایشی، تکرار خرید و حساسیت به فرض مقایسه. |
| [I19](../02-initiatives/store-operations/i19.md) | همیار شعبه؛ دستیار فارسیِ دستورالعمل | صحت پاسخ روی پرسش آزمون؛ نرخ ارجاع صحیح؛ زمان یافتن جواب؛ رضایت کارکنان. |
| [I20](../02-initiatives/store-operations/i20.md) | شیفت‌یار؛ زمان درست، نیروی مناسب | زمان خدمت؛ اضافه‌کاری واقعی؛ پایداری برنامه و انصاف توزیع شیفت. |
| [I21](../02-initiatives/new-revenue/i21.md) | فامیلی سازمانی؛ سبد دوره‌ای اداره و مجموعه | حاشیه پس از خدمت، وصول، تکرار و تحویل صحیح. |
| [I22](../02-initiatives/new-revenue/i22.md) | فامیلی مدیا؛ رسانه قابل‌اندازه‌گیری در فروشگاه | درآمد خالص رسانه، تمدید کمپین و کیفیت اندازه‌گیری؛ نه شمار نگاه حدسی. |
| [I23](../02-initiatives/new-revenue/i23.md) | دید تأمین‌کننده؛ گزارش کالا تا قفسه | رفع کمبود، کیفیت برنامه مشترک و مبلغ قرارداد واقعی؛ نه ارزش‌گذاری فرضی داده. |
| [I24](../02-initiatives/new-revenue/i24.md) | فامیلی ۲۴؛ نقطه فروش کوچک خارج شعبه | حاشیه هر نقطه پس از شارژ، زمان خرابی، دورریز و تکرار خرید. |
| [I25](../02-initiatives/store-operations/i25.md) | مدیر دیجیتال شعبه و نماینده | زمان حل مسئله؛ کار بازمانده؛ استفاده واقعی؛ نه تعداد نمودار. |
| [I26](../02-initiatives/circular-economy/i26.md) | بطری بده، اعتبار خرید بگیر | هزینه خالص هر ظرف؛ نرخ استفاده اعتبار؛ مراجعه افزایشی و تحویل به بازیافت‌گر. |
| [I27](../02-initiatives/circular-economy/i27.md) | فامیلی کم‌بسته؛ بازپرکنی مسئولانه | هزینه واقعی هر واحد، بازگشت مشتری، بسته‌بندی اجتناب‌شده و رخداد کیفیت. |
| [I28](../02-initiatives/circular-economy/i28.md) | تازگی‌سنج میوه؛ نمایش رسیدگی، نه گواهی سلامت | خطا در پیش‌بینی رسیدگی و رضایت؛ ضایعات به‌صورت مقایسه‌ای. |
| [I29](../02-initiatives/store-operations/i29.md) | کیت انبار متصل سبک | دقت دریافت/برداشت؛ مسیر طی‌شده؛ هزینه هر سفارش و برگشت دارایی. |
| [I30](../02-initiatives/strategy/i30.md) | شبیه‌ساز شعبه پیش از سرمایه‌گذاری | خطای مدل نسبت به واقعیت، تصمیم بهتر و هزینه آزمایش اجتناب‌شده قابل اثبات. |
