# صورت مسئله و فرضیه‌ها

این نمایه، مقادیر کامل فیلدهای ثبت قبلی را دوباره مرتب می‌کند؛ تحلیل، برآورد یا الزام جدیدی به کارت‌ها اضافه نشده است. اولویت و هزینه نسبی، پیشنهاد پژوهشگر هستند و بودجه یا تعهد فروشنده نیستند.

| شناسه | ابتکار | مسئله / فرضیه |
| --- | --- | --- |
| [I01](../02-initiatives/customer-experience/i01.md) | فامیلی همراه؛ سبد خرید در سقف بودجه | آیا مشتری پیش از رسیدن به صندوق می‌داند فاکتورش از بودجه عبور می‌کند؟ این نیاز باید با مشتری واقعی آزموده شود. |
| [I02](../02-initiatives/customer-experience/i02.md) | فامیلی پیدا کن؛ راهنمای کالا تا چراغ قفسه | یافتن کالای خاص میان برندها و اندازه‌های مشابه می‌تواند وقت مشتری و کارکنان را بگیرد. |
| [I03](../02-initiatives/customer-experience/i03.md) | چرخ خرید ماژولار؛ اول بارکد، بعد بینایی | آیا تجربه نمایش فاکتور و راهنمای خرید روی چرخ بهتر از گوشی است؟ هنوز فرضیه است. |
| [I04](../02-initiatives/customer-experience/i04.md) | صف هوشمند و صندوق سیار | مسئله اصلی طول صف است، نه الزاماً نبود صندوق خودپرداخت. |
| [I05](../02-initiatives/customer-experience/i05.md) | ترازوی بینا برای میوه و کالای فله | یافتن کد صحیح میوه/خشکبار می‌تواند کند یا همراه خطا باشد؛ مقدار آن در فامیلی نامعلوم است. |
| [I06](../02-initiatives/customer-experience/i06.md) | فامیلی مهمانی؛ سفارش آماده‌سازی‌شونده | فروشگاه می‌تواند مأموریت «آماده‌کردن مهمانی» را به‌جای فروش منفرد اقلام پشتیبانی کند؛ تقاضای آن باید آزموده شود. |
| [I07](../02-initiatives/customer-experience/i07.md) | تحویل در مسیر؛ جمع‌آوری سفارش و لاکر | برای بعضی مشتریان، زمان تحویل قطعی و توقف کوتاه از ارسال فوری ارزشمندتر است؛ فرضیه محلی. |
| [I08](../02-initiatives/customer-experience/i08.md) | حالت خرید آسان و دسترس‌پذیر | استفاده از ابزار جدید نباید شرط خرید یا باعث کنارگذاشتن افراد کم‌توان یا کم‌تجربه شود. |
| [I09](../02-initiatives/customer-experience/i09.md) | رسید و مرجوعی دیجیتال قابل پیگیری | گم‌شدن رسید یا ناهماهنگی کانال پشتیبانی می‌تواند تجربه پس از خرید را دشوار کند؛ خط پایه لازم است. |
| [I10](../02-initiatives/customer-experience/i10.md) | ویدئوی قابل خرید؛ از دستور غذا تا سبد شعبه | محتوای شبکه اجتماعی وقتی ارزش تجاری دارد که به خرید قابل انجام و قابل اندازه‌گیری برسد. |
| [I11](../02-initiatives/store-operations/i11.md) | قفسه تا اقدام؛ نه صرفاً داشبورد | فرضیه: ممکن است کالا در انبارک باشد ولی قفسه خالی بماند؛ قبل از پروژه اندازه‌گیری شود. |
| [I12](../02-initiatives/store-operations/i12.md) | قیمت یکسان در قفسه، چرخ و صندوق | نوآوری روی قیمت ناهماهنگ، اعتماد مشتری را تخریب می‌کند؛ ابتدا نرخ واقعی مغایرت تعیین شود. |
| [I13](../02-initiatives/store-operations/i13.md) | پیش‌بینی و سفارش پیشنهادی محلی | سفارش بیش از نیاز سرمایه را درگیر و سفارش کم فروش را محدود می‌کند؛ میزان واقعی هرکدام مجهول است. |
| [I14](../02-initiatives/store-operations/i14.md) | تازه‌نجات؛ انقضا، تخفیف و فروش مازاد | قلم نزدیک انقضا پیش از غیرقابل فروش‌شدن باید در گردش مسئولانه و قابل اندازه‌گیری قرار گیرد. |
| [I15](../02-initiatives/store-operations/i15.md) | سردبان؛ هشدار سرمایش متصل به تعمیرات | آیا خرابی یخچال یا بازماندن در قبل از آسیب به کالا تشخیص داده می‌شود؟ سوابق لازم است. |
| [I16](../02-initiatives/store-operations/i16.md) | انرژی‌بان؛ مصرف تا اقدام مهندسی | صورتحساب ماهانه به‌تنهایی علت مصرف غیرعادی هر بخش را آشکار نمی‌کند. |
| [I17](../02-initiatives/commercial/i17.md) | سود گمشده قرارداد؛ کنترل تخفیف و مطالبات | تخفیف حجمی، پاداش عملکرد یا سهم پروموشن ممکن است در قرارداد باشد؛ وجود مطالبه وصول‌نشده در فامیلی باید احراز شود. |
| [I18](../02-initiatives/commercial/i18.md) | تخفیف سودآور؛ آزمایش به‌جای فروش ظاهری | کمپین ممکن است فروش را زیاد کند اما سود یا خرید کل دوره را افزایش ندهد. |
| [I19](../02-initiatives/store-operations/i19.md) | همیار شعبه؛ دستیار فارسیِ دستورالعمل | کارکنان برای یافتن دستورالعمل معتبر یا حل مسئله روزمره نباید در چند فایل جست‌وجو کنند. |
| [I20](../02-initiatives/store-operations/i20.md) | شیفت‌یار؛ زمان درست، نیروی مناسب | تطبیق شیفت با اوج کار بدون فشار نامنصفانه بر کارکنان، مسئله برنامه‌ریزی است. |
| [I21](../02-initiatives/new-revenue/i21.md) | فامیلی سازمانی؛ سبد دوره‌ای اداره و مجموعه | سفارش تکراری ادارات می‌تواند با سقف بودجه و فهرست مصوب ساده شود؛ تقاضای واقعی سنجیده نشده است. |
| [I22](../02-initiatives/new-revenue/i22.md) | فامیلی مدیا؛ رسانه قابل‌اندازه‌گیری در فروشگاه | آیا برندها برای نمایش هدفمندِ موقعیتی و نتیجه قابل دفاع در فامیلی پول می‌پردازند؟ پیش از خرید تجهیزات آزموده شود. |
| [I23](../02-initiatives/new-revenue/i23.md) | دید تأمین‌کننده؛ گزارش کالا تا قفسه | اطلاعات عملکرد کالا می‌تواند برای برنامه‌ریزی مشترک مفید باشد؛ تمایل به پرداخت هنوز فرضیه است. |
| [I24](../02-initiatives/new-revenue/i24.md) | فامیلی ۲۴؛ نقطه فروش کوچک خارج شعبه | امکان خدمت به اداره/مجتمع در زمانی که شعبه دور یا بسته است؛ تقاضای محل و هزینه شارژ تعیین‌کننده‌اند. |
| [I25](../02-initiatives/store-operations/i25.md) | مدیر دیجیتال شعبه و نماینده | چند هشدار جدا بدون اولویت و مالک، تصمیم روزانه را سخت می‌کند؛ ابتدا جریان فعلی را بشناسیم. |
| [I26](../02-initiatives/circular-economy/i26.md) | بطری بده، اعتبار خرید بگیر | آیا بازگشت ظرف، مراجعه و بازیافت قابل رهگیری می‌سازد و هزینه آن تأمین می‌شود؟ باید آزموده شود. |
| [I27](../02-initiatives/circular-economy/i27.md) | فامیلی کم‌بسته؛ بازپرکنی مسئولانه | بسته‌بندی کمتر می‌تواند تمایز بسازد، ولی مسئولیت کیفیت، اندازه‌گیری و آلودگی باید روشن باشد. |
| [I28](../02-initiatives/circular-economy/i28.md) | تازگی‌سنج میوه؛ نمایش رسیدگی، نه گواهی سلامت | انتخاب میوه متناسب با زمان مصرف می‌تواند ارزش داشته باشد؛ حجم قلم هدف باید توجیه‌کننده باشد. |
| [I29](../02-initiatives/store-operations/i29.md) | کیت انبار متصل سبک | بازگشت سرمایه باید از خطای دریافت، زمان برداشت یا گم‌شدن دارایی مشخص بیاید، نه صرف نصب تگ. |
| [I30](../02-initiatives/strategy/i30.md) | شبیه‌ساز شعبه پیش از سرمایه‌گذاری | پیش از افزودن صندوق، تغییر چیدمان یا نصب دستگاه، اثر بر مسیر و ظرفیت بررسی شود. |
