# ریسک‌ها و مرزهای تصمیم

این نمایه، مقادیر کامل فیلدهای ثبت قبلی را دوباره مرتب می‌کند؛ تحلیل، برآورد یا الزام جدیدی به کارت‌ها اضافه نشده است. اولویت و هزینه نسبی، پیشنهاد پژوهشگر هستند و بودجه یا تعهد فروشنده نیستند.

| شناسه | ابتکار | ریسک و مرز |
| --- | --- | --- |
| [I01](../02-initiatives/customer-experience/i01.md) | فامیلی همراه؛ سبد خرید در سقف بودجه | نمایش موجودی کهنه، پیشنهاد نامناسب و فشار برای خرج بیشتر. رضایت و امکان استفاده بدون حساب ضروری است. |
| [I02](../02-initiatives/customer-experience/i02.md) | فامیلی پیدا کن؛ راهنمای کالا تا چراغ قفسه | نمایش دقیقِ مکان غلط از نبود نقشه بدتر است. درخواست هم‌زمان چند نفر، خاموشی چراغ و دسترس‌پذیری متنی باید طراحی شود. |
| [I03](../02-initiatives/customer-experience/i03.md) | چرخ خرید ماژولار؛ اول بارکد، بعد بینایی | شارژ، ضربه، نظافت، سرقت دستگاه و خطای اسکن. از کپی نرم‌افزار یا طراحی اختصاصی سازنده پرهیز شود. |
| [I04](../02-initiatives/customer-experience/i04.md) | صف هوشمند و صندوق سیار | کم‌دقتی دوربین، جابه‌جایی گلوگاه به کنترل خروج، یا نارضایتی مشتری. افراد به‌عنوان متخلف امتیازدهی نشوند. |
| [I05](../02-initiatives/customer-experience/i05.md) | ترازوی بینا برای میوه و کالای فله | شباهت ظاهری ارقام/کیفیت‌ها؛ دوربین وزن و سلامت غذا را تعیین نمی‌کند. |
| [I06](../02-initiatives/customer-experience/i06.md) | فامیلی مهمانی؛ سفارش آماده‌سازی‌شونده | فروش بیش از ظرفیت، تأخیر، آلرژن و تغییرات سفارش. کیفیت و ایمنی تابع فرایند مسئول بخش است. |
| [I07](../02-initiatives/customer-experience/i07.md) | تحویل در مسیر؛ جمع‌آوری سفارش و لاکر | گنجهِ بسته پستی، شاهد توان زنجیره سرد نیست. مواد یخچالی نباید در لاکر عادی بمانند. |
| [I08](../02-initiatives/customer-experience/i08.md) | حالت خرید آسان و دسترس‌پذیر | برچسب‌زدن به افراد، جمع‌آوری غیرضروری داده سلامت و رابط فقط صوتی/رنگی. |
| [I09](../02-initiatives/customer-experience/i09.md) | رسید و مرجوعی دیجیتال قابل پیگیری | سیاست مرجوعی نباید توسط مدل ساخته شود؛ اعتبار خرید/کالای تازه قواعد متفاوت دارد. |
| [I10](../02-initiatives/customer-experience/i10.md) | ویدئوی قابل خرید؛ از دستور غذا تا سبد شعبه | بازدید ویدئو با فروش برابر نیست؛ توصیه حساس پزشکی یا تبلیغ پنهان برای کودکان وارد نشود. |
| [I11](../02-initiatives/store-operations/i11.md) | قفسه تا اقدام؛ نه صرفاً داشبورد | دوربین سقفی لزوماً جزئیات قفسه را نمی‌بیند؛ فضای خالی موجودی پنهان را اثبات نمی‌کند؛ هشدار بی‌مسئول ارزشی ندارد. |
| [I12](../02-initiatives/store-operations/i12.md) | قیمت یکسان در قفسه، چرخ و صندوق | تغییر خودسرانه قیمت، اختلاف آفلاین/آنلاین و قیمت‌گذاری فردی پنهان. قیمت نهایی از مرجع فروش است. |
| [I13](../02-initiatives/store-operations/i13.md) | پیش‌بینی و سفارش پیشنهادی محلی | صفر فروش ناشی از نبود کالا نباید صفر تقاضا فرض شود؛ جهش قیمت با رشد تعداد یکی نیست. |
| [I14](../02-initiatives/store-operations/i14.md) | تازه‌نجات؛ انقضا، تخفیف و فروش مازاد | فروش کالای منقضی/نامطمئن ممنوع؛ از مدل برای تمدید تاریخ یا تأیید سلامت استفاده نشود. سود بازیابی و کاهش ضایعات دوباره‌شماری نشوند. |
| [I15](../02-initiatives/store-operations/i15.md) | سردبان؛ هشدار سرمایش متصل به تعمیرات | دمای هوا لزوماً دمای مغز کالا نیست. فرمان سرمایش/دیفراست فقط با تأیید مهندس و مسئول کیفیت. |
| [I16](../02-initiatives/store-operations/i16.md) | انرژی‌بان؛ مصرف تا اقدام مهندسی | مقایسه خام ماه سرد و گرم گمراه‌کننده است. صرفه‌جویی پروژه دارای خورشیدی را فقط به AI نسبت ندهیم. |
| [I17](../02-initiatives/commercial/i17.md) | سود گمشده قرارداد؛ کنترل تخفیف و مطالبات | مدل قرارداد را تفسیر نهایی یا مطالبه را خودکار قطعی نکند؛ محرمانگی شرایط تجاری رعایت شود. |
| [I18](../02-initiatives/commercial/i18.md) | تخفیف سودآور؛ آزمایش به‌جای فروش ظاهری | افزایش مبلغ ناشی از تورم، پیش‌خرید و انتقال فروش از شعب دیگر؛ قیمت قبلی ساختگی مجاز نیست. |
| [I19](../02-initiatives/store-operations/i19.md) | همیار شعبه؛ دستیار فارسیِ دستورالعمل | پاسخ بی‌منبع و دسترسی فراتر از نقش؛ مدیرعامل خودمختار یا تصمیم‌گیر اخراج نباشد. |
| [I20](../02-initiatives/store-operations/i20.md) | شیفت‌یار؛ زمان درست، نیروی مناسب | جمع‌آوری داده زیستی یا امتیازدهی پنهان افراد، تصمیم استخدام/اخراج خودکار. |
| [I21](../02-initiatives/new-revenue/i21.md) | فامیلی سازمانی؛ سبد دوره‌ای اداره و مجموعه | فروش زیاد همراه مطالبات دیرهنگام؛ اعتباردهی نیازمند شریک/تأیید مالی است. |
| [I22](../02-initiatives/new-revenue/i22.md) | فامیلی مدیا؛ رسانه قابل‌اندازه‌گیری در فروشگاه | فروش داده شخصی، شلوغی بصری، تبلیغ گمراه‌کننده و جایگزین‌کردن حاشیه کالا با درآمد ظاهری آگهی. |
| [I23](../02-initiatives/new-revenue/i23.md) | دید تأمین‌کننده؛ گزارش کالا تا قفسه | افشای اطلاعات رقابتی یا گروه‌های بسیار کوچک؛ کنترل سطح دسترسی و تجمیع ضروری است. |
| [I24](../02-initiatives/new-revenue/i24.md) | فامیلی ۲۴؛ نقطه فروش کوچک خارج شعبه | سود ظاهری بدون هزینه تأمین/نظافت/قطعه؛ سیاست فروش اقلام محدود باید رعایت شود. |
| [I25](../02-initiatives/store-operations/i25.md) | مدیر دیجیتال شعبه و نماینده | هشدار زیاد و اولویت تخمینیِ نمایش‌داده‌شده به‌عنوان سود قطعی. |
| [I26](../02-initiatives/circular-economy/i26.md) | بطری بده، اعتبار خرید بگیر | نظام ودیعه خارجی با پاداش از بودجه فروشگاه یکی نیست؛ تقلب دوباره‌ثبت، آلودگی و تأخیر تخلیه. |
| [I27](../02-initiatives/circular-economy/i27.md) | فامیلی کم‌بسته؛ بازپرکنی مسئولانه | هر بطری دلخواه مناسب نیست؛ نتیجه تجربه تاریخی خارجی، مجوز فروش یا تضمین ایران نیست. |
| [I28](../02-initiatives/circular-economy/i28.md) | تازگی‌سنج میوه؛ نمایش رسیدگی، نه گواهی سلامت | تعمیم از آووکادو به همه میوه یا تشخیص آلودگی غذایی نادرست است. |
| [I29](../02-initiatives/store-operations/i29.md) | کیت انبار متصل سبک | BLE به‌تنهایی موجودی دقیق هر کالا نمی‌دهد؛ هم‌پوشانی با WMS فعلی و داده تکراری کنترل شود. |
| [I30](../02-initiatives/strategy/i30.md) | شبیه‌ساز شعبه پیش از سرمایه‌گذاری | انیمیشن زیبا با مدل معتبر فرق دارد؛ خروجی شبیه‌سازی نتیجه واقعی محسوب نشود. |
