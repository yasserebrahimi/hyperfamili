# قالب کارت ایده با سه دیدگاه

## فیلدهای پیشنهادی
| فیلد | محتوا |
|---|---|
| شناسه و نام | شناسه ثابت؛ عدم ساخت پرونده تکراری برای یک قابلیت |
| منشأ | عبارت مدیر / کارت پیشین / پیشنهاد تازه؛ وضعیت و تاریخ هرکدام |
| مسئله | مشاهده تأییدشده یا فرضیه نیازمند آزمون |
| نقش‌ها | مشتری، کارکنان درگیر، مدیر تصمیم‌گیر و مالک داده |
| پیش از تغییر | مراحل واقعی، خطاها و زمان؛ در نبود شاهد نامشخص |
| پس از تغییر | جریان کامل همراه استثناها و کمک انسانی |
| منفعت مشتری | اثر قابل آزمون و معیار آن |
| منفعت و بار کارکنان | زمان، دقت، ثبت اضافه، آموزش و پشتیبانی |
| تصمیم مدیر | گزینه، اختیار، مسئول اجرا و معیار نتیجه |
| داده و سامانه موجود | منبع مرجع، تازگی، دسترسی و محدودیت اتصال |
| سخت‌افزار/نرم‌افزار | ضروری در نسخه کوچک / قابل تعویق؛ بدون پیش‌فرض AI |
| هزینه کل | توسعه، اتصال، آموزش، پشتیبانی و تجهیز؛ در نبود استعلام نامشخص |
| معیار پذیرش و توقف | خط پایه، روش مقایسه و شرط بازگشت به روش قبلی |
| ملاحظات | حریم خصوصی، کیفیت، ایمنی، انصاف و جلوگیری از تصمیم خودکار حساس |
| شواهد | منبع دقیق با تاریخ و سطح دسترسی؛ دمو، هدف و تحقق جدا |
