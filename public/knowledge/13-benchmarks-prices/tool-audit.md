# ممیزی ابزارها و محدودیت‌های اجرای پژوهش

## استفاده واقعی ابزارها
Files برای شناسایی و محتوای پروژه استفاده شد؛ ZIP مرجع در محیط بررسی و باز شد. جست‌وجوی وب و Firecrawl برای صفحه محصول/تعرفه/علمی به کار رفتند. Parallel Search چند خوانش انجام داد و سپس سقف رایگان آن پر شد؛ این محدودیت با ادعای جست‌وجوی کامل پوشانده نشد.

سه کار عامل Firecrawl برای قیمت داخلی/خارجی/نرم‌افزار به سقف اعتبار تعیین‌شده رسیدند و با وضعیت ناموفق/خروجی جزئی پایان یافتند. نتایج آنها فقط سرنخ بودند و موارد مهم جدا بازخوانی شدند؛ سه تحقیق مستقل کامل ادعا نمی‌شود.

Powerset مقایسه مخزن‌های متن‌باز انجام داد؛ آن را ابزار تعیین قیمت فروشگاه یا صورت مالی فرض نکردیم.۹مخزن از درخواست۱۰تایی برگشت و نبود LightGBM در نمایه را نبود پروژه فرض نکردیم. برای۱۵مخزن، صفحه رسمی جدا باز شد؛ درخواست مستقیم شبکه محیط به APIگیت‌هاب با DNSfailure شکست خورد و به‌عنوان ممیزی موفق API گزارش نشد.

Consensus برای یافتن و خواندن چکیده مقاله ESL استفاده شد؛ منبع اولیه ناشر دنبال شد. Skillهای روش کار و verification خوانده شدند؛ اجرای چندایجنت مستقل یا استفاده موفق از تمام نام‌های افزوده‌شده کاربر ادعا نمی‌شود.

هیچ خرید، تماس فروشنده، ثبت‌نام، سفارش، فرم، اسکن امنیتی، ورود حساب یا اجرای کد دانلودشده انجام نشد. کد ساخت فایل‌ها فقط ابزار داخلی تولید/کنترل بود. Excel با artifact_tool ساخته می‌شود؛ نه ابزار مجوزدهی یا سرویس مالی.
