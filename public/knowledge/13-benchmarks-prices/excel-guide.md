# راهنمای فایل قیمت‌نامه Excel

فایلExcel جدا تحویل می‌شود و داخلZIP نیست. نام: `HyperFamili_Benchmark_Pricebook_2026-10-16.xlsx`.

| شیت | محتوا |
| --- | --- |
| راهنما | دامنه، حدود و شیوه استفاده |
| مدل هزینه | نرخ‌های آزمایشی، نفرساعت طبقه‌ای و مثال‌های قابل محاسبه |
| طرح‌ها |۱۰۲ردیف با ایران، خارج، قیمت و دامنه پیشنهادی |
| قیمت‌ها |۶۷مقدار خام، مدل، واحد، ارز، شرایط، URL و تاریخ |
| منابع |۴۴صفحه و کیفیت دسترسی |
| پژوهش‌ها |۱۰مدخل علمی و نوع مطالعه |
| مخزن‌ها |۱۵مخزن و نکته مجوز/بررسی |

## ورودی‌ها
در «مدل هزینه»، B6/B7/B8 نرخ‌های حساسیت کم/پایه/زیادند. این اعداد مفروضات تحلیلگرند، نه تعرفه بازار. B9/B10برای ارز وB11برای هزینه‌های نامشخص خالی گذاشته شده‌اند؛ به‌صورت خودکار به قیمت‌ها اعمال نمی‌شوند. پرکردن این سلول‌ها به‌تنهایی تعرفه مالیاتی یا محاسبه واردات ایجاد نمی‌کند.

فرمول‌های هزینه طبقه‌ای درE15:F18 و در ستون‌هایN/Oشیت طرح‌ها به ورودی‌ها متصل‌اند. ردیف‌های بدون دامنه نرم‌افزاری، خالی می‌مانند نه صفر. مثال‌هایE22:F26 ارزهای متفاوت دارند و نباید با هم جمع شوند.

## خواندن جزئیات
جدول‌ها فیلترپذیرند؛ متن‌های بلند درسلول حفظ شده‌اند. برای شرح کامل، پروندهBPوPSرا درMarkdown بخوانید. URLها در ستون جدا و ورودی‌های مدل با یادداشت منشأ همراه‌اند.
