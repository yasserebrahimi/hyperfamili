# دفتر تعارض‌ها و اصلاح برداشت‌ها

## مواردی که در کنترل تغییر کردند
| مورد | نتیجه کنترل |
|---|---|
| EMO۷کیلووات کارامید | متن صفحه۵۷میلیون تومان؛ برداشت۵۷٫۵میلیون کنار گذاشته شد |
| پاپ‌کورن پایاپارس | نمایه‌های۶۸۰/۷۲۰ و کاتالوگ۷۸۰/۸۴۰ همسان نیستند؛ تاریخ/مدل/اعتبار باید تأیید شود؛ میانگین ساخته نشد |
| Mini1 | متن۳٫۵میلیون تومان و متادیتا۳۵میلیون ریال هم‌ارزند؛ اشتباه ده‌برابری نشد |
| نام پلن حضور سازمانی | پلن۱۰۰هزار تومانی در صفحه اتنسی، نام «کسرا کلاد» دارد؛ عنوان دقیق جایگزین نام کلی شد. مثال سالانه۸۴میلیون بر نرخ ماهانه بدون تخفیف است |
| رایبرد | قیمت به ازای نمایشگر معلوم، مدت نامعلوم؛ سالانه‌سازی نشد |
| LUMOplay | نوع دلار از انتخابگر روشن نیست؛ مبلغ با USD قطعی جمع نشد |
| کیوسک نوید | قیمت کیوسک به بودجه کامل خودپرداخت گروسری تعمیم نیافت |
| قیمت داده‌لاگر |۲۰٫۵میلیون بالای صفحه با ردیف‌های DS81/DS83 مخلوط نشد |
| دامنه پایاپارس |.com و.ir بدون سند یک شخصیت حقوقی فرض نشدند؛ URLهای نامرتبط کنار گذاشته شدند |
| LightGBM |نشانی microsoft/LightGBM به lightgbm-org/LightGBM هدایت شد؛ تغییر مسیر ثبت شد |
| PM4Py |نشانی قدیمی به process-intelligence-solutions/pm4py هدایت شد |
| ThingsBoard |README فعلی تغییر نسخه۴٫۴بهBUSL را می‌گوید؛ ادعای متن‌باز رایگان بی‌قید از متن قدیمی تکرار نشد |
| مقاله داخلی |تاریخ فارسی و انگلیسی دوره داده تفاوت دارند؛ بی‌ردپا یکسان‌سازی نشد |

این اصلاحات لایه جدیدند؛ فایل‌های قدیمی دست‌نخورده مانده‌اند تا تاریخچه حذف نشود. برای تصمیم امروز، دفتر قیمت و هشدارهای جدید بر متن تاریخی مقدم‌اند.
