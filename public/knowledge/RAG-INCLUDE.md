# انتخاب فایل برای نمایه پرسش‌وپاسخ

این فهرست **179 فایل مرجع پیشنهادی** را مشخص می‌کند. هدف، جلوگیری از دوباره‌شماری متن پرونده‌ها در فهرست‌ها، JSON و آرشیو قدیمی است؛ پیاده‌سازی سامانه RAG در این نوبت انجام نشده است.

## قواعد پاسخ‌گویی
خروجی باید شناسه منبع، تاریخ، مرحله واقعی و محدودیت را حفظ کند. فرضیه HC با نمونه GR و منبع SR متفاوت است. «منبع اولیه» را به معنی «نتیجه مستقل» تلقی نکنید. فایل‌های legacy فقط برای تاریخچه و با برچسب نسخه قدیمی بازیابی شوند.
