# Vazirmatn font

Self-hosted, unmodified variable WOFF2 from Vazirmatn **v33.003**, covering font weights 100–900.

- Official project: https://github.com/rastikerdar/vazirmatn
- Source font: https://raw.githubusercontent.com/rastikerdar/vazirmatn/v33.003/fonts/webfonts/Vazirmatn%5Bwght%5D.woff2
- Upstream license and authors are preserved in `OFL.txt` and `AUTHORS.txt`.
- Local filename: `Vazirmatn.woff2` (file bytes unchanged).
- SHA-256: `4e3fa217d38fdafc1fea4414ceb58ca5e662cf0ab5fa735a8c8c20e8b42cad92`

`standalone.py` embeds this WOFF2 and its license into the standalone HTML so typography works without a server or internet.
